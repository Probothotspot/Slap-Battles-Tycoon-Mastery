# Slap Battles Tycoon Mastery — 0.2.0

Парная подготовка Main/Alt и защита кнопки Destruct. Arena Bot не изменяется.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Probothotspot/Slap-Battles-Tycoon-Mastery/main/loader.lua"))()
```

## Запуск

1. Запусти одинаковый loader на обоих аккаунтах в одном сервере.
2. Main: экипируй Tycoon, выбери Main Account, введи username Alt и нажми Connect.
3. Alt: выбери Alt Account, введи username Main, нажми Connect и включи Start Farming.
4. Main: включи Quest 1, затем Start Farming.

Connect ищет точный username без учёта регистра, не DisplayName. Connected Player
означает присутствие игрока на сервере, а не подтверждение работы второго скрипта.
Уведомление появляется справа снизу. При отсутствии игрока — Players Not Found.

Main входит через Workspace.Lobby.Teleport1, отправляет E, ждёт секунду и отправляет
E ещё раз. Только после появления НОВОГО тайкуна и его Destruct создаёт локальную
платформу и перемещается на Y=10000. Собственная модель ищется по точному имени
`ÅTycoon` + текущий Player.Name; Destruct — непосредственный дочерний BasePart.
Пути и схема модели основаны на предоставленных пользователем игровых данных.

Alt пытается экипировать Diamond через ClickDetector стойки Workspace.Lobby.Diamond,
проверяя фактический leaderstats.Glove или Tool. Этот путь стойки ещё не подтверждён:
если стойка/функция недоступна, экипируй Diamond вручную и перезапусти Start Farming.
Далее Alt входит в красный портал, ждёт стабильный сигнал Y=10000 в течение 1.5 сек,
находит Destruct именно у Main, телепортируется в центр и проверяет расстояние перед E.
Сигнал Y=20000/30000 распознаётся, но квесты 2/3 пока не автоматизированы.

## Проверка камня и ограничения

Положительный маркер: булево поле/атрибут IsRock, Rocked, RockMode или DiamondActive
в персонаже, либо видимая коллизионная BasePart Rock/diamondrock внутри персонажа.
Эти имена — диагностические кандидаты, **не подтверждённая структура Diamond**.
Anchored само по себе не считается доказательством превращения.
Если маркер неизвестен, после первого E скрипт ждёт до 16 сек и останавливается
с объяснением. Повтор возможен только при явном false, максимум три попытки.
Подтверждённый камень не переключается повторной E. Для продолжения при неизвестном
маркере нужно снять фактическую структуру персонажа до/после превращения.
Расстояние HRP от Destruct <=4 studs — грубая проверка размещения, не доказательство
того, что другим игрокам полностью перекрыт доступ к кнопке.

Попадание в Destruct может активировать уничтожение. Коллизия может вытолкнуть Alt.
Сервер может отменить телепорт. Платформа локальная, не общая для обоих клиентов.
StreamingEnabled может скрыть персонажа Main на высоте 10000 от Alt: в таком случае
Alt остаётся в ожидании, не выдумывая сигнал. Обмена сообщениями или внешнего сервера нет.
Остановка Main убирает сигнал возвращением к сохранённой позиции у тайкуна.
При смерти, выходе партнёра, пропаже кнопки или сигнала действия останавливаются.
Камень автоматически не отключается. Неизвестные состояния не выдаются за успех.

## Прогресс мастерства

По игровому скриншоту пользователя: 500 защит, 15000 очков, 150 GOD STATUS убийств.
**Камень на кнопке и ожидание на высоте не выполняют Quest 1 сами по себе.**
Текущий релиз автоматизирует предложенную подготовку/защиту, а не удары и убийства.
Поле Quest 1 показывает только реально прочитанный счётчик из видимой игровой панели
Tycoon Mastery. При неизвестном значении отображается —. Main останавливается на
подтверждённых 500/500, после чего Alt теряет сигнал и останавливает наблюдение.

Загрузчик сохраняет loading modules 0/1, скрывает полоску после появления GUI,
при сбое пишет только error. Окно фиолетовое с анимацией градиента, перетаскиванием,
ползунками Quest 1 / Start Farming и подписью By: Probothotspot.

## Модули и проверки

- PairProtocol.lua: точное сопоставление владельца, никнеймов, высот.
- PairActions.lua: игровые действия и чтение фактических состояний.
- PairController.lua: отменяемая последовательность, таймауты и подтверждения.
- PairGui.lua: Main/Alt, поля, уведомления, анимированные переключатели.
- main.lua: интеграция; LegacyMain.lua/Gui.lua сохраняют прежнюю панель наблюдения.
  Для неё можно выставить PairMode=false в config.lua.
- Остальные Quest/Progress/Adapter модули сохранены.

Проверки Lua 5.4: tests.lua, pair_tests.lua, pair_gui_tests.lua,
pair_action_tests.lua, pair_loader_tests.lua, loader_tests.lua. Модели движка проверяют последовательность,
таймауты, GUI, loader и очистку; живую физику, репликацию и права executor не заменяют.
