# Slap Battles Tycoon Mastery

Отдельный проект Tycoon Mastery, версия **0.1.1**. Существующий Arena Bot остаётся
в своём репозитории на версии **0.9.1** и этим проектом не изменяется.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Probothotspot/Slap-Battles-Tycoon-Mastery/main/loader.lua"))()
```

## Что работает

Загрузчик показывает ту же верхнюю чёрную полоску, что у Arena Bot:
`loading modules 0/1` во время загрузки всех модулей как одного комплекта,
`loading modules 1/1` после инициализации; после появления основного GUI полоска
скрывается. При ошибке видна только надпись `error`, детали остаются в отчёте.
Есть кеш модулей, ограничение ожидания 20 секунд и очистка предыдущего запуска.

В GUI одновременно загружаются все три модуля квестов, можно выбрать текущий,
начать/приостановить наблюдение, свернуть, перетащить и закрыть окно. Размер
подстраивается под экран. Три карточки показывают условия, известный прогресс
и источник счётчика. Прогресс читается из видимой панели Tycoon Mastery, если
совпали область, описание задания и ожидаемый знаменатель. Без данных — `—`.
Неоднозначные значения пропускаются; старое наблюдение помечается через 10 секунд.

**Это стартовая панель и модули условий/наблюдения, не готовый автофарм.** Перемещение,
размещение и улучшение тайкуна, удары и убийства пока не автоматизированы.
Старт включает наблюдение, а не выполнение игровых действий. Модули не вызывают
RemoteEvent и не начисляют себе прогресс. Привязка игровых объектов и автоматизация
каждого квеста — следующий этап после проверки актуальной структуры игры.

## Три задания

| Модуль | Задание на предоставленном игровом скриншоте | Ожидаемый счётчик |
| --- | --- | ---: |
| `QuestDefense.lua` | Ударять игроков рядом со своим тайкуном | 500 |
| `QuestMainIsland.lua` | Накопить очки на главном острове | 15 000 |
| `QuestGodStatus.lua` | Убивать игроков при GOD STATUS | 150 |

Требования сверены с игровым скриншотом пользователя от 20 октября 2026 года:
500 защит тайкуна, 15 000 очков на главном острове и **150**, а не 200, убийств
при GOD STATUS. На скриншоте показаны исходные счётчики 0/500, 0/15000 и 0/150;
это не подставляется в живой прогресс. Старый общественный
[справочник](https://roblox-slap-battles.fandom.com/wiki/Tycoon) остаётся дополнительной
ссылкой; скриншот имеет приоритет. `RequirementsVerified=true`, но
`LiveVerified=false`: пути игровых объектов и точные условия засчитывания удара
ещё не проверены. Один скриншот не подтверждает радиус защиты или нужное улучшение.
Если знаменатель изменился, парсер не выдаст другое число за подходящий прогресс.

## Файлы

- `loader.lua`, `manifest.lua` — загрузка комплекта и список систем.
- `main.lua`, `config.lua`, `Gui.lua` — приложение, настройки и интерфейс.
- `QuestCatalog.lua`, `QuestCore.lua` — требования и общая логика карточек.
- `QuestDefense.lua`, `QuestMainIsland.lua`, `QuestGodStatus.lua` — три независимых задания.
- `Progress.lua` — строгий разбор и хранение абсолютных наблюдённых значений.
- `Adapter.lua` — чтение GUI и точка подключения проверенных игровых данных.
- `Cleanup.lua`, `Logger.lua` — очистка и сообщения.
- `tests.lua` — проверки модулей, счётчиков, GUI, повторного запуска и очистки.
- `loader_tests.lua` — полоска 0/1, сетевые/синтаксические ошибки, таймаут и отмена.

## Подключение игры

После запуска доступен `getgenv().SlapBattlesTycoonMastery` (или одноимённое поле
`_G`, если getgenv отсутствует). `app:BindGame(provider)` подключает функцию,
читающую **уже проверенные реальные** игровые объекты. Поддерживаются поля:

```lua
-- Форма результата provider; отсутствующие поля означают «неизвестно».
{
    OwnedTycoon = true,        -- свой тайкун действительно существует
    EnemyNearTycoon = false,   -- проверенная область защиты
    OnMainIsland = true,      -- проверенная игровая область
    GodStatus = false,         -- действующий статус, не предположение по очкам
    Progress = { defense = 42, points = 1200, god = 3 },
    Source = "Проверенные игровые счётчики",
}
```

Это описание интерфейса, не готовый provider с догадками о путях объектов.
Отсутствующие поля не заменяются на false. Жизнь и экипированная перчатка всегда
читаются с локального персонажа. Значения provider имеют приоритет над эвристикой
GUI. Смена provider очищает прежние показания. `app:BindGame(nil)` отключает его.
Запись локального файла не может завершить серверный квест; счётчики не сохраняются
как подмена прогресса. При повторном входе они читаются из игры заново.

## Проверка

Из корня проекта: `lua tests.lua` и `lua loader_tests.lua` (Lua 5.3+). Модели Roblox проверяют логику,
не воспроизводят живой рендеринг, физику и актуальный формат игрового интерфейса.
Загрузчик рассчитан на клиентскую среду с `loadstring` и `game:HttpGet`.
